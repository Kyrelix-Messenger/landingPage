# Проверка PageSpeed / Lighthouse

Обновление 19 октября 2026: декоративный WebGL-слой, наклон окна, параллакс и блик внутри интерактивного чата удалены вместе с three.js и react-three-fiber. Свечение за курсором на карточках возможностей и в нижнем блоке сохранено. Демо-чат, переключение панелей, темы и языки сохранены. Ниже приведены лабораторные замеры от 18 октября, до удаления эффектов.

После удаления проверены оба режима прозрачности: WebGL-контексты не создаются, canvas и 3D-запросов нет, движение мыши не меняет окно или фон. Проверки проекта: 125 тестов, lint, типы и сборка проходят; 15 тестов удалённой 3D-подсистемы удалены вместе с ней.

## Что исправлено

- **Лишний JavaScript.** Старая настройка `manualChunks` помещала общий `scheduler` в чанк R3F, поэтому React DOM импортировал 3D-рендерер даже на телефонах. Сначала разделение исправили через `onlyExplicitManualChunks`. 19 октября вся 3D-графика и её зависимости были удалены; отдельного 3D-чанка в сборке больше нет.
- **Блокирующий CSS.** Тот же собранный CSS встроен в HTML на этапе prerender. Отдельного запроса таблицы стилей перед первым показом больше нет. Внешний вид сохранен.
- **Порядок заголовков.** «Messages», имя собеседника и название экрана звонков в демонстрации являются подписями интерфейса. Они заменены с `h3` на `p` с прежними CSS-классами. Содержательные H1–H3 страницы сохранены; Lighthouse проверяет их порядок без ошибок.
- **Фавикон после переключения языка.** Ссылки на ресурсы в head закрепляются за исходным адресом перед изменением URL через History API. Переключение `/` → `/ru/` больше не меняет адрес фавикона на несуществующий `/ru/favicon.svg`.

В сборку добавлены проверки порядка заголовков, отсутствия 3D-preload и отдельного блокирующего CSS. Проверки выполняются для всех 10 языков. Новые зависимости приложения не добавлялись.

Скриншоты полной страницы до/после при ширине окна 1440 и 390 px совпали попиксельно с отключенными анимациями. В браузере также проверены запуск двух WebGL canvas на компьютере, отсутствие 3D-запросов на сенсорном устройстве, отправка сообщения в демо, сравнение тем, смена языка и отсутствие ошибочных запросов фавикона. Все 140 тестов, lint, проверка типов и сборка проходят.

## Что означает оставшаяся диагностика

В категории unused JavaScript остаётся около 30 КиБ библиотечного кода, который не используется немедленно при первом показе. Это оценка покрытия кода в одном сценарии; удаление всех таких участков нарушило бы работу интерактивных функций. Оценка производительности уже находится в зелёной зоне.

Пункт о предварительных соединениях сообщает об отсутствии подходящих сторонних доменов. Все необходимые ресурсы сайта находятся на том же домене, поэтому дополнительные preconnect не нужны.

GitHub Pages отдаёт `Cache-Control: max-age=600`. По решению владельца хостинг и этот срок кэша оставлены без изменений. HTML-метатеги не переопределяют HTTP-кэширование ресурсов.

Для воспроизведения использовались Lighthouse CLI с `--output=json`, обычный мобильный профиль и `--preset=desktop`. Исходные отчёты сохранены локально в `.playwright-mcp/lighthouse-before-mobile.json`, `.playwright-mcp/lighthouse-after-mobile.json` и `.playwright-mcp/lighthouse-after-desktop.json`.

Справка: [разделение модулей Rollup](https://rollupjs.org/configuration-options/#output-onlyexplicitmanualchunks), [загрузка модулей Vite 7](https://v7.vite.dev/config/build-options.html#build-modulepreload), [HTTP-кэш в Lighthouse](https://developer.chrome.com/docs/lighthouse/performance/uses-long-cache-ttl).
