# SEO Kyrelix

Реализованы технические идеи из [обсуждения](https://chatgpt.com/share/6ad4cb1a-a218-83ed-b008-f8bb4f9baeed). Верстка, оформление, видимые тексты разделов и состав функций сохранены.

## Что исправлено

| Раньше                                                    | Теперь                                                                                                    |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Пустой React root в HTML, контент только после JavaScript | Готовые HTML-страницы на всех 10 существующих языках, затем гидратация React                              |
| Язык зависел от браузера и localStorage при одном URL     | `/` для английского, `/ru/`, `/zh/`, `/es/`, `/fr/`, `/de/`, `/ar/`, `/pt/`, `/ja/`, `/pl/` для переводов |
| Не было canonical и hreflang                              | Собственный canonical каждой версии, взаимные hreflang и `x-default`                                      |
| Переключение языка только через JavaScript                | Настоящие ссылки, сохранено плавное переключение, работает история браузера                               |
| Неполные данные для превью ссылки                         | Локализованные Open Graph и Twitter, PNG 1200 × 630                                                       |
| Не было поисковых файлов и структурированных данных       | Автоматические robots.txt, sitemap.xml и JSON-LD                                                          |
| Заголовок первого экрана скрывался до анимации            | Текст виден сразу и без JavaScript                                                                        |

Английские и русские Title/Description уточнены под веб-мессенджер, чаты, группы и каналы. Остальные метаданные используют существующие переводы. Структурированные данные описывают Organization, WebSite, WebPage и WebApplication без вымышленных цен, рейтингов или возможностей.

Отдельные адреса переводов и ссылки между ними соответствуют [рекомендациям Google по многоязычным сайтам](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites) и [hreflang](https://developers.google.com/search/docs/specialty/international/localized-versions). URL определяет язык; сохраненная настройка и язык браузера не подменяют содержание опубликованной страницы. Старые ссылки `?lang=ru` продолжают работать и преобразуются в `/ru/` через History API.

## Проверки

```sh
npm run lint
npm run check:types
npm test
npm run build
```

В сборку включен `check:seo`: проверяются все готовые HTML-файлы, наличие H1 и основного текста, соответствие языка/направления, canonical, hreflang, JSON-LD, ссылки на переводы, пути JS/CSS/favicon, карта сайта и изображение превью.

В браузере проверены загрузка всех 10 версий, русский HTML с отключенным JavaScript, переключение языка, Back, старые query-ссылки, светлая/темная темы, FAQ и код 404 для неизвестного адреса. На ширине 1440 px координаты и размеры основных разделов совпали с исходным сайтом. На 390 px сохранились ширина 390 px и высота страницы 8435 px, без горизонтального переполнения.

## Публикация

Публикуется содержимое `dist/` существующим GitHub Actions workflow. Node-сервер для сайта не нужен. Хостинг должен отдавать `index.html` из языковых каталогов и настоящий 404 для отсутствующих файлов. Относительные пути ресурсов сохраняют работу предпросмотра в каталоге GitHub Pages; canonical и sitemap указывают на основной домен `https://kyrelix.org`.

После выкладки:

1. Проверить `/ru/`, `/robots.txt`, `/sitemap.xml` и `/og-image.png` на основном домене.
2. Подтвердить сайт в Google Search Console, Bing Webmaster Tools и Яндекс Вебмастере, затем отправить `https://kyrelix.org/sitemap.xml`. Коды подтверждения и доступ к этим кабинетам в проект не передавались.
3. В Google Search Console проверить исходный/отрендеренный HTML главной и `/ru/`, индексацию и выбранные canonical.
4. Измерить Core Web Vitals после публикации и накопления реальных посещений. Изменения устраняют зависимость основного текста от JavaScript; измеренные показатели LCP/INP/CLS и рост позиций не заявляются.

Страницы `/features/`, `/channels/`, блог и правовые документы из стратегического плана не создавались: для них нужен отдельный согласованный контент. Они не включены в sitemap. Текущая реализация оптимизирует существующий лендинг и его переводы.
